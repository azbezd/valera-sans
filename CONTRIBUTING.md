# Feedback and official development

Please report unreadable letter combinations, missing characters or rendering issues through [Issues](https://github.com/azbezd/valera-sans/issues). Include the word, font style, size, application/browser, operating system and a screenshot when possible. Avoid including private document content.

The project uses a custom no-modification license. Source availability is for inspection and reproducibility, not an invitation to publish derivative fonts. Obtain the author's permission before submitting source changes or redistributing modified files. The author maintains official versions.

For authorized maintenance, follow [BUILD.md](docs/BUILD.md), run validation and update the changelog. A successful build alone does not replace visual review of words and spacing.
