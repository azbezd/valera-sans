Буквы выросли из рукописных листов и сканов автора. Их неровности, хвостики и наклоны сохранены в векторных контурах. Это шрифт для подписей к работам, афиш, заголовков и личных проектов, которым нужен собственный почерк.

## Начать использовать

Скачай [готовый комплект](https://github.com/azbezd/valera-sans/releases/download/v0.5.1/ValeraSans-0.5.1-fonts.zip). Для компьютера установи **TTF или OTF**, выбрав один формат. Для сайта используй **WOFF2** и готовый CSS.

| Начертание | Вес | Форматы |
|---|---:|---|
| Light | 300 | TTF · OTF · WOFF2 |
| Regular | 400 | TTF · OTF · WOFF2 |
| Semibold | 600 | TTF · OTF · WOFF2 |

```html
<link rel="stylesheet" href="fonts/web/valera-sans.css">
```

```css
.handwriting {
  font-family: "Valera Sans", sans-serif;
  font-weight: 400;
  font-kerning: normal;
  font-feature-settings: "calt" 1;
}
```

На сайте расположи CSS рядом с тремя WOFF2. [Подробности установки и использования](docs/USAGE.md).

## Буквы и поведение

Русский алфавит с Ё/ё, базовая латиница A–Z/a–z, цифры, знаки, ₽ и №: **170 символов и 180 глифов**. У `а` и `a` сохранены характерные хвостики. Латинская `r` меняет форму после строчной `e`: в `er` работает текучий вариант, в `re` и отдельно — более вертикальный. Это встроенное правило OpenType `calt`.

Во всех трёх толщинах есть парный кернинг и табличные цифры `tnum`. [Пример и переключатели](https://azbezd.github.io/valera-sans/specimen/) показывают настоящий шрифт.

Выпуск **0.5.1 — предварительный**. Light и Semibold пока экспериментальные; расширенная латиница, курсив, переменная ось и специальный хинтинг не входят в комплект. [Что проверено и какие есть ограничения](docs/VALIDATION.md).

## Указать автора

Можно использовать шрифт в коммерческих проектах. Добавь один доступный кредит на проект: в описании, титрах, выходных данных или на странице авторства.

> Valera Sans — Валерий Исаченков · [valerasketch.ru](https://valerasketch.ru)

Изменение, переименование и распространение изменённого шрифта требуют отдельного разрешения автора. Исходники опубликованы для изучения и воспроизводимости; проект **не заявляется как open source**. [Полная лицензия](LICENSE) · [Готовые варианты кредита](ATTRIBUTION.md).
