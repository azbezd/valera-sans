Шрифт создан по рукописным образцам автора. В контурах букв сохранены неровности, хвостики и наклоны, которые делают почерк узнаваемым. Valera Sans подойдёт для подписей к работам, афиш и заголовков.

## Начать использовать

Скачай [готовый комплект](https://github.com/azbezd/valera-sans/releases/download/v0.5.2/ValeraSans-0.5.2-fonts.zip). Для компьютера установи **TTF или OTF**, выбрав один формат. Для сайта используй **WOFF2** и готовый CSS.

| Начертание | Вес | Форматы |
|---|---:|---|
| Light | 300 | TTF · OTF · WOFF2 |
| Regular | 400 | TTF · OTF · WOFF2 |
| Semibold | 600 | TTF · OTF · WOFF2 |

```html
<link rel="stylesheet" href="fonts/web/valera-sans.css">
```

```css
.handwriting {
  font-family: "Valera Sans", sans-serif;
  font-weight: 400;
  font-kerning: normal;
  font-feature-settings: "calt" 1;
}
```

Для сайта помести файл CSS в одну папку с тремя файлами WOFF2. [Подробнее об установке и использовании](docs/USAGE.md).

## Особенности шрифта

Русский алфавит с Ё/ё, базовая латиница A–Z/a–z, цифры, знаки, ₽ и №: **170 символов и 180 глифов**. У кириллической `а` и латинской `a` сохранены характерные хвостики. Латинская `r` меняет форму после строчной `e`: в сочетании `er` она более плавная, а в `re` и отдельно — более вертикальная. Подмена происходит автоматически благодаря функции OpenType `calt`.

Во всех трёх начертаниях настроен парный кернинг — расстояния между сочетаниями букв. Функция `tnum` делает цифры одинаковыми по ширине, чтобы они ровно стояли в столбцах. [На странице примеров](https://azbezd.github.io/valera-sans/specimen/) можно набрать свой текст и попробовать эти настройки.

Версия **0.5.2 — предварительная**. Начертания Light и Semibold пока экспериментальные. Расширенная латиница и курсив ещё не поддерживаются; плавного изменения толщины и специальной настройки для отображения в мелком размере (хинтинга) пока нет. [Результаты проверок и ограничения](docs/VALIDATION.md).

## Как указать автора

Можно использовать шрифт бесплатно, в том числе в коммерческих проектах. При публикации работы укажи название шрифта и автора — например, в описании, титрах, выходных данных или разделе «О проекте». Одного упоминания на проект достаточно:

> Valera Sans — Валерий Исаченков · [valerasketch.ru](https://valerasketch.ru)

Изменение, переименование и распространение изменённого шрифта требуют отдельного разрешения автора. Исходники можно изучать и использовать для повторной сборки официальной версии. **Публикация исходников не даёт разрешения изменять шрифт.** [Полный текст лицензии](LICENSE) · [Примеры указания авторства](ATTRIBUTION.md).
