# Работы автора / Author's artwork

Живопись и графика Валерия Исаченкова использованы здесь как примеры оформления шрифтом Valera Sans. Исходные изображения сохранены без перерисовки и изменения цвета.

- [Молодость](https://valerasketch.ru/work/molodost/) — акрил, акриловые маркеры.
- [Гранат и мандарины](https://valerasketch.ru/work/granat-i-mandariny/) — масло, картон.
- [Форель с розмарином и лимоном](https://valerasketch.ru/work/forel-s-rozmarinom-i-limonom/) — акварель, карандаши, чернила.
