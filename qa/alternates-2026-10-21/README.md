## Повторить сборку

Из `project/`, при исходниках HEAD до этой работы в `.orig/` (`git archive <коммит> sources | tar -x -C .orig --strip-components=1`):

```sh
python qa/alternates-2026-10-21/integrate.py   # пишет sources/*.ufo и tests/alternates-spec.json
python scripts/build.py
python qa/alternates-2026-10-21/fixtures.py    # тестовые таблицы из модели (не из сборки)
python scripts/validate.py
```

`vector/<Style>/*.json` — контуры вариантов после векторизации (целые координаты, ровно то, что идёт в UFO).

## Что делает integrate.py по порядку

1. Добавляет варианты как `<глиф>.altN`, знак «°» — как `uni00B0`.
2. Полирует контуры всех глифов (`../contour-cleanup-2026-10-21/polish.py`): капли, шипы, обрубленные концы; убирает лишнюю точку у «j» и вручную чистит её крючок.
3. Увеличивает все формы цифр до ≈95% высоты прописных при прежней толщине штриха (`../digits-2026-10-22/scale_digits.py`, с 0.6.1); пары с цифрами пересчитываются формулой 0.4.
4. Чередование в `calt`: контекстные r/у (как в 0.5.5) → `Rotate` (фазы, одна буква подряд всегда меняет форму) → `KeepAfter` (после любой формы «а» — обычная «д»).
5. Кернинг: формула 0.4 (`refine_all_pairs.py`) для вариантов, группы по профилю, пары-исключения.
6. Пересчёт пар «X + j» после удаления точки.
7. «Λ»-буквы (л, Л, д, Д, А, A): пустота сверху → сближение.
8. Зазор: край не ближе 50 ед. (буквы/цифры), 40 (знаки) — `touch.py`, по точкам контура.
9. «л» после строчных с хвостиком: левее и на 25 ед. выше (отдельный lookup `Lift`, чтобы не терялся кернинг следующей пары).
10. Сближение рыхлых пар до 40-го процентиля пустоты своей группы, край не ближе 50 ед.
11. Пары «буква + д» — значения 0.5.5: подчёркивание «д» подныривает под предыдущую букву.

Проверка — `scripts/alternates_model.py`: по спецификации предсказывает формы, кернинг и подъём; `validate.py` сверяет с HarfBuzz, `check-browser` — ширины в Chrome.

## Пробы

`text-*.png` — набор в трёх весах; `al-*.png`, `lift-*.png`, `clearance-words.png`, `final-words.png`, `ad-zoom.png` — «было | стало» по замечаниям автора.
